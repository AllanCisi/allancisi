Tenho experiência prática em projetos envolvendo autenticação, integração com banco de dados, automações, deploy em cloud e containerização com **Docker**. Também desenvolvo interfaces com **React/Next.js** quando necessário para entregar soluções completas.

### 🚀 Projetos em destaque

**Genesis Sandbox (GSBox)**  
Plataforma full-stack para análise de dados Web3, com API REST em **Java/Spring Boot**, PostgreSQL, sincronização automática via Cron Jobs, deploy em OCI/Vercel e backend containerizado com Docker.  
🔗 https://gsbox.vercel.app/

**LoginSystem**  
Sistema de autenticação em **Java/Spring Boot** com Spring Security, OAuth2, Argon2 + Pepper, CSRF, confirmação por e-mail, 2FA/TOTP e Redis para gerenciamento de sessões.  
🔗 https://github.com/AllanCisi/LoginSystem
